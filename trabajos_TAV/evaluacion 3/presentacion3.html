Función: Recomendar Contenidos

PR_RECOMENDAR_CONTENIDOS
JEFE:

"Escucha, necesitamos un sistema de recomendaciones inteligente. Cuando un usuario abre la app, quiero mostrarle contenido que realmente le interese, basado en lo que ya ha visto."

EMPLEADO:

"Entendido. ¿Cómo funciona exactamente?"

JEFE:

"Simple. El sistema analiza el historial de visualización del usuario y encuentra los 3 géneros que más ha visto. Luego, recomienda 5 series o películas de esos géneros que NO haya visto todavía."

SELECT DISTINCT c.titulo_contenido, c.poster_url, g.nombre_genero FROM CONTENIDOS c JOIN CONTENIDO_GENEROS cg ON c.id = cg.id_contenido WHERE cg.id_genero IN ( -- Obtener los 3 géneros más frecuentes del usuario SELECT id_genero FROM ( SELECT cg.id_genero, COUNT(*) as frecuencia FROM HISTORIALES h JOIN CONTENIDO_GENEROS cg ON h.id_contenido = cg.id_contenido WHERE h.id_perfil = p_id_perfil GROUP BY cg.id_genero ORDER BY frecuencia DESC ) WHERE ROWNUM <= 3 ) AND c.id NOT IN ( -- Excluir contenido ya visto SELECT id_contenido FROM HISTORIALES WHERE id_perfil = p_id_perfil ) AND ROWNUM <= 5;
EMPLEADO:

"Perfecto. Esto aumentará el engagement porque cada usuario verá contenido personalizado. ¿Qué pasa si hay un error?"

JEFE:

"Usamos un EXCEPTION handler. Si algo falla, registramos el error pero no rompemos la experiencia del usuario. La función devuelve los resultados mediante un cursor de salida."

Función: Registrar Contenido

PR_REGISTRAR_CONTENIDO
JEFE:

"Cuando llegue contenido nuevo al catálogo, necesitamos registrarlo correctamente. Pero antes de insertar, debes verificar que no exista ya."

EMPLEADO:

"¿Cómo evitamos duplicados?"

JEFE:

"Primero hacemos un SELECT COUNT(*) para verificar si el título ya existe. Si existe, lanzamos un error personalizado. Si no existe, procedemos con el INSERT."

-- Verificar si ya existe SELECT COUNT(*) INTO v_existe FROM CONTENIDOS WHERE UPPER(titulo_contenido) = UPPER(p_titulo); IF v_existe > 0 THEN RAISE_APPLICATION_ERROR(-20001, 'El contenido ' || p_titulo || ' ya existe.'); ELSE INSERT INTO CONTENIDOS ( id_tipo, titulo_contenido, titulo_original, fecha_salida, id_demografia, id_studio, poster_url, banner_url, trailer_url ) VALUES ( p_id_tipo, p_titulo, p_titulo_orig, p_fecha_salida, p_id_demografia, p_id_studio, p_poster_url, p_banner_url, p_trailer_url ); COMMIT; END IF;
EMPLEADO:

"¿Y si algo sale mal durante el INSERT?"

JEFE:

"Por eso usamos EXCEPTION WHEN OTHERS. Si hay cualquier error, hacemos un ROLLBACK para deshacer los cambios y luego lanzamos el error hacia arriba con RAISE. Esto mantiene la integridad de los datos."

EMPLEADO:

"Excelente. Así garantizamos que nunca tengamos contenido duplicado y si hay un problema, podemos rastrear exactamente qué ocurrió."
