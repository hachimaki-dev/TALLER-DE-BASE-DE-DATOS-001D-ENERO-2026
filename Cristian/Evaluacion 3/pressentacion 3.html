05. INTELIGENCIA DE NEGOCIO

Funciones: FN_INGRESOS_POR_JUEGO y FN_TOTAL_HORAS

Uso de NVL para nulos y UPPER para robustez de texto.

FUNCTION FN_INGRESOS_POR_JUEGO(
    p_id_juego NUMBER
) RETURN NUMBER IS
    v_total NUMBER;
BEGIN
    SELECT NVL(SUM(monto_pagado), 0)
    INTO v_total
    FROM TRANSACCIONES
    WHERE id_juego = p_id_juego 
    AND UPPER(estado) = 'COMPLETADA'; 
    -- Normalización para integridad

    RETURN v_total;
END;

NOTA: La normalización con UPPER() previene errores por inconsistencias en el formato de datos.
