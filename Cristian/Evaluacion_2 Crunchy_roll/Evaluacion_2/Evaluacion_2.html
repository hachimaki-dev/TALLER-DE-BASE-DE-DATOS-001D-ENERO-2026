1.1. Selección del Alcance y Procesos

Para esta auditoría, hemos seleccionado dos procesos críticos que garantizan la salud financiera y operativa de la plataforma.

💰 Auditoría de Planes y Bonificaciones (Financiero)

  • Tablas: USUARIOS, SUSCRIPCIONES, PLANES_SUSCRIPCION.
  • Objetivo: Verificar planes válidos y calcular bonos. Detectar inconsistencias en precios o nombres no autorizados.

👁️ Auditoría de Actividad de Perfiles (Operativo)

  • Tablas: USUARIOS, PERFILES, HISTORIALES.
  • Objetivo: Validar la regla: "El historial se guarda en el perfil". Detectar "Perfiles Zombie" (vacíos) y "Cuentas Abandonadas".

1.3. Estrategia de Adaptación (Lógica PL/SQL)

A. Validación de Jerarquía (Cursores Anidados)

Adaptamos la lógica usando Nested Loops:

  1. Bucle Principal: Recorre los perfiles del usuario.
  2. Bucle Secundario: Busca historial específico de ese perfil.

Esto cumple estrictamente la regla de que el consumo pertenece al perfil.

B. Manejo de Errores (Excepciones)

  • Técnicos: NO_DATA_FOUND, VALUE_ERROR.
  • De Negocio: e_todos_perfiles_vacios (Cuentas abandonadas) y e_plan_invalido.

C. Persistencia (Impacto BD)

Se creó la tabla LOG_AUDITORIA. Todos los scripts hacen INSERT para dejar evidencia trazable.

Requisito Previo: Tabla de Log

Para cumplir con el requerimiento de "Impacto en Base de Datos", es obligatorio crear esta tabla antes de ejecutar los scripts:

CREATE TABLE LOG_AUDITORIA (
    id NUMBER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    mensaje VARCHAR2(250), -- Guardamos el error o éxito
    fecha TIMESTAMP DEFAULT SYSTIMESTAMP
);
/

Sin esta tabla, los scripts fallarán al intentar insertar la auditoría.

Código 1: Auditoría de Planes

Valida precios y nombres de planes. Lanza excepción si el plan es desconocido.

DECLARE
    e_plan_invalido EXCEPTION;
    v_plan_actual VARCHAR2(100);
    v_usuario_actual VARCHAR2(100);
    
    CURSOR C_SUB IS
        SELECT u.nombre_usuario, p.nombre_plan, p.precio_plan
        FROM USUARIOS u JOIN SUSCRIPCIONES s ON u.id = s.id_usuario
        JOIN PLANES_SUSCRIPCION p ON s.id_plan = p.id
        WHERE s.estado = 'activo';
BEGIN
    FOR r_usuario IN C_SUB LOOP
        v_plan_actual := r_usuario.NOMBRE_PLAN;
        v_usuario_actual := r_usuario.nombre_usuario;
        
        -- Validación Técnica
        IF r_usuario.precio_plan <= 0 THEN RAISE VALUE_ERROR; END IF;

        -- Lógica de Bonos
        IF r_usuario.NOMBRE_PLAN = 'Premium' THEN
            DBMS_OUTPUT.PUT_LINE('Usuario: ' || r_usuario.nombre_usuario || ' -> Bono 50%');
        ELSIF r_usuario.NOMBRE_PLAN = 'Estándar' THEN
            DBMS_OUTPUT.PUT_LINE('Usuario: ' || r_usuario.nombre_usuario || ' -> Bono 25%');
        ELSE 
            RAISE e_plan_invalido; -- Salto a Excepción
        END IF;
    END LOOP;
EXCEPTION
    WHEN VALUE_ERROR THEN
        DBMS_OUTPUT.PUT_LINE('[ERROR CRÍTICO] Precio inválido.');
        ROLLBACK;
    WHEN e_plan_invalido THEN
        DBMS_OUTPUT.PUT_LINE('[ALERTA] Plan desconocido: ' || v_plan_actual);
        INSERT INTO LOG_AUDITORIA (mensaje, fecha) 
        VALUES ('Plan inválido: ' || v_usuario_actual, SYSDATE);
        COMMIT;
END;
/

Código 2: Auditoría de Perfiles

Valida la regla de historial. Lanza excepción si la cuenta está abandonada.

DECLARE
    v_id_busqueda NUMBER := 6; 
    v_nombre_usuario USUARIOS.nombre_usuario%TYPE;
    v_tiene_historial BOOLEAN;
    v_perfiles_con_contenido NUMBER := 0;
    v_total_perfiles NUMBER := 0;
    e_todos_perfiles_vacios EXCEPTION;
BEGIN
    SELECT nombre_usuario INTO v_nombre_usuario FROM USUARIOS WHERE id = v_id_busqueda;
    
    FOR r_perfil IN (SELECT id, nombre_perfil FROM PERFILES WHERE id_usuario = v_id_busqueda) LOOP
        v_total_perfiles := v_total_perfiles + 1;
        v_tiene_historial := FALSE;

        FOR r_historial IN (SELECT * FROM HISTORIALES WHERE id_perfil = r_perfil.id) LOOP
            v_tiene_historial := TRUE;
        END LOOP;

        IF v_tiene_historial THEN
            v_perfiles_con_contenido := v_perfiles_con_contenido + 1;
        ELSE
            INSERT INTO LOG_AUDITORIA (mensaje, fecha) 
            VALUES ('ALERTA: Perfil vacío "' || r_perfil.nombre_perfil || '"', SYSTIMESTAMP);
        END IF;
    END LOOP;
    
    -- Validación de regla de negocio
    IF v_total_perfiles > 0 AND v_perfiles_con_contenido = 0 THEN
        RAISE e_todos_perfiles_vacios;
    END IF;
    COMMIT;
EXCEPTION
    WHEN NO_DATA_FOUND THEN
        DBMS_OUTPUT.PUT_LINE('[ERROR] Usuario no existe.');
    WHEN e_todos_perfiles_vacios THEN
        INSERT INTO LOG_AUDITORIA (mensaje, fecha) 
        VALUES ('CUENTA INACTIVA: ' || v_nombre_usuario, SYSDATE);
        COMMIT;
END;
/
